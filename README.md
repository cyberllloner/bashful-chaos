## ✨ Collection

- [`hello.sh`](hello.sh) — A cheerful greeting.
- [`coin.sh`](coin.sh) — Makes an important decision for you.

## 🚀 Quick Start

All you need is Bash. No dependencies, no setup ritual, no elaborate configuration—just clone and run.

```bash
git clone https://github.com/cyberllloner/bashful-chaos.git
cd bashful-chaos

bash hello.sh
bash coin.sh
```

> **Prefer the terminal life?**
>
> ```bash
> chmod +x hello.sh coin.sh
> ./hello.sh
> ./coin.sh
> ```

## 🧰 Contributing

Got a tiny script with a big personality? We would love to see it.

1. **Fork** this repository.
2. **Create** a small, readable Bash script.
3. **Test** it in a safe environment.
4. **Add** it to the collection list above.
5. **Open** a pull request.

Please keep submissions:

- 🧩 Small and focused
- 📖 Easy to read
- 😂 Friendly and funny
- 🔒 Harmless and safe
- 🐚 Compatible with common Bash environments

For larger ideas or questions, open an issue and start the conversation.

## 🤝 Community

Bug reports, feature ideas, silly improvements, and quality pull requests are always welcome.

Before contributing, remember: **if a script is destructive or unexpectedly powerful, it probably belongs in another repository—or needs clear opt-in behavior.**
